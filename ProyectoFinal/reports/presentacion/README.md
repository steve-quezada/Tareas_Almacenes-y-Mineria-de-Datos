# Reports

Proyecto Quarto para la presentación `Mineria de Textos Avanzada`.

## Estructura

- `_quarto.yml`: configuración del proyecto.
- `index.qmd`: fuente principal de la presentación.
- `styles/`: tema SCSS usado por RevealJS.
- `images/`: imágenes utilizadas por la presentación.
- `_site/`: salida generada por Quarto al renderizar.
- `legacy/`: archivos anteriores conservados como referencia.

## Render

Desde esta carpeta:

```bash
quarto render
```

La presentación generada queda en `_site/index.html`.
